System design · for the team

One recovery loop for any system where agents and humans depend on shared infrastructure.

Callers send work through a front door to many serving units on physical infrastructure. When something breaks, one controller with two tool collections (the Doctors) notices, tests fixes in a shadow twin, acts within policy and proves the repair.

Architecture

Agents and humans → vLLM replicas → Nexus Doctors

How real runs reach the UI

The views above run on the SimPy twin. The real loop runs on the Brev box and writes files. One operator app on the box serves those records and starts named faults; the UI server adds the token, adapts the agent's trail to the twin's run shape and streams it, so the same panels can show either. Where the loop applies

AI Datacenter is built. The other four are concepts: designed, not operational.

Easiest second build: Logistics

Closest match to the datacenter shape, every action is reversible, and order flow is a textbook SimPy queue.

Strongest story: Healthcare, as decision support

Unflagged lab results are the same silent failure as the dropped tool call. Nexus proposes and simulates; a named human approves anything patient-facing.

What is real today
  • In the twin, Doctor reasoning is a rule-based stand-in. Tool calls, actions and verification run for real on the SimPy twin.
  • On the Brev fleet, Nemotron runs the loop for real. After the harness redesign, same weights: known faults 7/12 → 11/12, held-out v1 2/12 → 9/12 (rules 3/12), held-out v2 10/12 → 12/12, and 0 false VERIFIED in 36 runs (4 before). Its runs, the scoreboard and live fleet frames reach the UI server, and the React results page, 3D replay and Break it live use them.
  • The twin is uncalibrated; it has not been fitted to Brev Prometheus or DCGM data yet.
  • On Brev, the silent vLLM #32926 drop reproduces 3/3 (HTTP 200, health 200, 0 parsed tool calls; BFCL 0.83 → 0.00), as do the loud tool-calling faults.
  • Healthcare, Agriculture, Education and Logistics are concepts. Their tool names are illustrative.
