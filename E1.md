# E1 handoff — live general-agent acceptance

## What changed

Nexus no longer contains a Brev-specific backend or hardcoded canary/status
tools. The target publishes an environment manifest, and the controller builds
its typed read-only tools from that manifest. The tool-call incident is one
environment configuration, shown in `data/example-environment-manifest.json`.

The same controller can therefore diagnose another system without changing the
agent loop: expose different resources, probes, metrics, artifact sections, and
repair actions in the manifest.

## 1. Pull and verify

```bash
git pull origin main
git rev-parse HEAD
git status --short
python --version
python -m unittest discover -s tests -v
python -m scripts.capability_smoke_test --mode scripted --runs 3
```

The scripted tests and smoke test make no LLM calls.

## 2. Verify the live Nemotron tool-call path

```bash
export NEMOTRON_BASE_URL="http://<agent-host>:<port>/v1"
export NEMOTRON_MODEL="<served-model-name>"
export NEMOTRON_TIMEOUT_SECONDS="60"
python -m scripts.capability_smoke_test --mode live --runs 3
```

Set `NEMOTRON_API_KEY` only if required. This command makes real LLM calls and
must produce one model-selected `describe_environment` call per run.

## 3. Expose the generic target-environment API

The live target adapter may be any service or language. It must implement:

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/environment` | Return the capability manifest |
| GET | `/resources` | Return bounded current resource inventory |
| POST | `/resources/{id}/state` | Return requested state fields |
| POST | `/resources/{id}/configuration` | Return requested, redacted config keys |
| POST | `/logs/query` | Return bounded, filtered logs |
| POST | `/metrics/query` | Return one declared metric/window |
| POST | `/probes/{id}/run` | Run one declared probe with typed inputs |
| POST | `/artifacts/read` | Read one declared section of a known artifact |

`GET /environment` should initially return the checked-in example manifest.
Every other endpoint must reject undeclared resources, probes, metrics, keys,
and artifact sections. Never expose shell execution, arbitrary paths, complete
environment dumps, or credentials.

For the tool-call incident, the probe result should include an `artifact_id` so
the agent can request `raw_generation` and `structured_response` from the same
request. Configuration must be effective runtime state, not intended values.

## 4. Run the complete live agent

The preferred inner-loop input is a structured trigger. Copy and adjust
`data/example-diagnostic-input.json`, keeping observations bounded and redacted:

```bash
python -m nexus.app --input data/example-diagnostic-input.json
```

The controller validates every referenced resource against the environment
manifest and records every initial observation as immutable `ev-*` evidence
before the first model call.

A manual run is also supported for debugging:

```bash
export NEXUS_ENVIRONMENT_URL="http://<target-adapter-host>:<port>"
export NEXUS_ENVIRONMENT_TIMEOUT_SECONDS="30"
python -m nexus.app "The target returns HTTP 200 but emits no structured tool call. Diagnose the problem."
```

The manual form creates a structured trigger with no initial observations. It
is less representative of the intended live integration.

Set `NEXUS_ENVIRONMENT_API_KEY` only if required. The run writes append-only
events and evidence beneath `artifacts/agent-runs/<run-id>/`.

Acceptance requires the real model—not `ScriptedNemotronClient`—to request the
needed evidence and return either:

- `PLAN` with real `ev-*` citations;
- `REQUIRES_APPROVAL` for a declared non-automatic action; or
- `ABSTAIN` with a concrete evidence or capability limitation.

The current runtime diagnoses and prechecks repairs. It does not execute a
mutation, so `PRECHECK` is authorization plus captured before-state, not proof
that a repair ran.

## Stop conditions

Stop and report the bounded error and commit SHA if the adapter cannot capture
required evidence, healthy and broken trials differ in unrelated inputs, an
interface would require arbitrary shell/filesystem access, credentials appear
in artifacts, or Nemotron does not emit native tool calls.
